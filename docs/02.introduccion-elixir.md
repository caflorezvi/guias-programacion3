# Elixir

Elixir es un lenguaje de programación funcional, concurrente y de tipado dinámico. Fue creado en 2011 por **José Valim**, programador brasileño y miembro de la comunidad de Ruby on Rails. Se ejecuta sobre la máquina virtual de Erlang (BEAM) y utiliza las capacidades de concurrencia y tolerancia a fallos proporcionadas por el ecosistema de Erlang y OTP.

En esta guía se abordarán los siguientes temas:

- Origen del lenguaje Elixir y su relación con Erlang, la BEAM y OTP.
- Características principales y usos comunes de Elixir.
- Instalación de Erlang y Elixir.
- El intérprete interactivo (IEx) y el primer programa.
- Configuración del entorno de trabajo con Visual Studio Code.

## La base de Elixir: Erlang, la BEAM y OTP

José Valim buscaba un lenguaje que combinara la productividad y la sintaxis elegante de Ruby con una solución nativa para la concurrencia y la tolerancia a fallos. En lugar de construirlo todo desde cero, decidió apoyarse en la **plataforma de Erlang**, creada en los años 80 para sistemas de telecomunicaciones que debían permanecer activos 24/7 sin interrupciones. La filosofía de Elixir puede resumirse así: *"la productividad y elegancia de Ruby sobre la potencia y robustez de Erlang"*.

El código Elixir no se ejecuta directamente sobre el sistema operativo, sino que se compila a *bytecode* que corre sobre la **BEAM** (*Bogdan/Björn's Erlang Abstract Machine*), la máquina virtual de Erlang. La BEAM es para Elixir lo que la JVM es para Java, solo que fue diseñada desde el inicio para ejecutar miles de procesos concurrentes y para recuperarse de fallos.

Sobre la BEAM se apoya **OTP** (*Open Telecom Platform*), el conjunto de principios y herramientas que Erlang y Elixir usan para organizar la concurrencia. Su idea central es **"dejarlo fallar" (*let it crash*)**. En lugar de anticipar cada error posible con código defensivo, el sistema se divide en procesos pequeños vigilados por **supervisores**. Si un proceso falla, su supervisor lo vuelve a iniciar desde un estado inicial conocido, y el resto del sistema sigue funcionando.

## Características clave de Elixir

- **Funcional**: promueve el uso de funciones puras, la inmutabilidad y la composición de funciones. Es el paradigma central de Elixir.
- **Concurrente**: permite crear procesos ligeros que pueden ejecutarse de forma concurrente. Estos procesos tienen un bajo consumo de recursos y pueden comunicarse mediante el envío de mensajes. La concurrencia forma parte de la plataforma sobre la que se ejecuta Elixir y no depende de una librería externa.
- **Tolerante a fallos**: los procesos están aislados entre sí, por lo que un fallo en un proceso no implica necesariamente que otros procesos fallen. Mediante los supervisores de OTP, los procesos que fallan pueden reiniciarse de acuerdo con una estrategia definida.
- **Escalable**: la BEAM puede distribuir la ejecución de procesos entre los núcleos disponibles de una máquina. Además, los procesos pueden comunicarse con procesos que se ejecutan en otras máquinas, lo que permite construir sistemas distribuidos.
- **Interoperable con Erlang**: Elixir se ejecuta sobre la BEAM y puede utilizar funciones y bibliotecas del ecosistema de Erlang directamente, lo que permite aprovechar gran parte de su ecosistema desde Elixir.

## Usos comunes

Aunque Elixir puede usarse para muchos tipos de aplicaciones, es especialmente popular en:

- Desarrollo de aplicaciones web (con el framework Phoenix).
- Sistemas de mensajería y comunicación en tiempo real.
- Servicios backend de alta concurrencia y baja latencia.

## Ambiente de trabajo con Elixir

Elixir se puede instalar en GNU/Linux (en sus distintas distribuciones), MacOS y Windows.

### 1. Instalación de Elixir y Erlang

Ingrese a [la página oficial de instalación de Elixir](https://elixir-lang.org/install.html?utm_source=chatgpt.com) y siga las instrucciones correspondientes a su sistema operativo. **Elixir depende de Erlang**, por lo que ambos deben estar instalados.

En **GNU/Linux y macOS**, las instrucciones de la página de Elixir permiten instalar Erlang y Elixir. En **Windows**, primero debe instalar Erlang desde [la página oficial de descargas de Erlang](https://www.erlang.org/downloads.html?utm_source=chatgpt.com) y posteriormente instalar Elixir.

> ⚠️ **Importante (GNU/Linux):** Los paquetes disponibles en los repositorios de algunas distribuciones (`apt`, `yum`, etc.) pueden estar **varias versiones atrasados** con respecto a las versiones oficiales. Si el gestor de paquetes instala una versión antigua, se recomienda utilizar el instalador oficial o un gestor de versiones como [mise](https://mise.jdx.dev/?utm_source=chatgpt.com) o [asdf](https://asdf-vm.com/?utm_source=chatgpt.com), que permiten instalar y cambiar entre versiones específicas de Erlang y Elixir.

Para verificar que todo se haya instalado correctamente, abra una terminal (CMD en Windows) y ejecute el siguiente comando:

```bash
elixir -v
```

La salida muestra **dos** datos importantes, uno por cada herramienta instalada:

```bash
Erlang/OTP 29 [erts-17.0.5] [source] [64-bit] [smp:10:10] [ds:10:10:10] [async-threads:1] [jit] [dtrace]

Elixir 1.20.2 (compiled with Erlang/OTP 29)
```

La primera línea confirma que **Erlang/OTP** está instalado, y la segunda que **Elixir** lo está y sobre qué versión de Erlang fue compilado. Los números pueden variar según su instalación y sistema operativo; las versiones al momento de escribir este documento son **Elixir 1.20.2** sobre **Erlang/OTP 29**.

> **⚠️ Versión mínima para el curso:** se requiere **Elixir 1.15 o superior**, con **Erlang/OTP 26 o superior**. Si su salida muestra números menores, actualice antes de continuar con las siguientes guías.

> **⚠️ Importante:** En Windows, puede ser necesario reiniciar el computador después de la instalación para que las variables de entorno se actualicen correctamente. Si después de reiniciar, el comando `elixir -v` no funciona o `iex` no se reconoce, asegúrese de que las rutas de Erlang y Elixir estén correctamente configuradas en las variables de entorno del sistema.

### 2. Primer programa en Elixir

El primer programa que se suele escribir en cualquier lenguaje de programación es "¡Hola, mundo!". En Elixir, puede hacerlo de dos maneras: usando el intérprete interactivo (IEx), que veremos a continuación, o creando un archivo `.exs` y ejecutándolo, lo cual haremos más adelante en la sección de Visual Studio Code.

El **intérprete interactivo (IEx)** ejecuta código Elixir línea por línea. No está diseñado para ejecutar programas completos, sino para probar fragmentos de código y explorar el lenguaje.

En la terminal, escriba el siguiente comando para iniciar el intérprete interactivo de Elixir (IEx):

```bash
iex
```

> **⚠️ Importante (Windows):** En **PowerShell**, `iex` está reservado como alias del comando `Invoke-Expression`, por lo que **no iniciará** el intérprete de Elixir y producirá un error confuso. En PowerShell debe escribir `iex.bat`, o bien abrir una terminal **CMD**. Tenga esto presente también en la terminal integrada de Visual Studio Code, que en Windows usa PowerShell de manera predeterminada.

Y escriba lo siguiente:

```elixir
IO.puts("¡Hola, mundo!")
```

Al dar **Enter**, debería ver lo siguiente en la consola.

```bash
¡Hola, mundo!
:ok
```

`IO` es el módulo de entrada y salida, y su función `puts` imprime texto en la consola. El resultado `:ok` indica que la operación se realizó correctamente.

>**⚠️ Importante:** Para salir de `iex`, presione `Ctrl + C` dos veces.

El ayudante `h` también es muy útil. Escrito solo, `h()` muestra un menú de ayuda, y seguido del nombre de una función muestra **la documentación oficial de esa función** sin salir de la terminal. Por ejemplo, `h IO.puts` explica qué hace, qué parámetros recibe y qué retorna. Es la forma más rápida de consultar el lenguaje mientras se programa.

### 3. Control de versiones con Git

Instale Git desde [la página oficial de descargas de Git](https://git-scm.com/downloads?utm_source=chatgpt.com). Aunque no es una herramienta específica de Elixir, es una herramienta ampliamente utilizada en proyectos de software para mantener un historial de los cambios realizados en el código y facilitar el trabajo colaborativo.

Después de instalarlo, configure su identidad ejecutando los siguientes comandos en la terminal:

```bash
git config --global user.name "Su Nombre"
git config --global user.email "sucorreo@uniquindio.edu.co"
```

### 4. Instalación de Visual Studio Code

Para programar en Elixir es recomendable utilizar un editor de código fuente que facilite la escritura, organización y ejecución del código. **Visual Studio Code (VS Code)** es un editor ampliamente utilizado que admite múltiples lenguajes de programación, incluido Elixir, y puede ampliarse mediante extensiones que agregan funcionalidades específicas.

Ingrese a [la página oficial de descarga de Visual Studio Code](https://code.visualstudio.com/Download?utm_source=chatgpt.com) e instálelo.

### 5. Instalar extensiones en Visual Studio Code

Ingrese a Visual Studio Code (VS Code) e instale las siguientes extensiones:

- **[ElixirLS: Elixir support and debugger for VS Code](https://marketplace.visualstudio.com/items?itemName=JakeBecker.elixir-ls)** *(indispensable)*: aporta resaltado de sintaxis, autocompletado, detección de errores mientras se escribe, documentación al pasar el cursor sobre una función y formateo automático del código.
- **[Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)** *(recomendada)*: muestra los errores y advertencias **junto a la línea** que los produce, en lugar de dejarlos ocultos en el panel inferior. Ayuda mucho a detectar equivocaciones de sintaxis apenas ocurren.
- **[Live Share](https://marketplace.visualstudio.com/items?itemName=MS-vsliveshare.vsliveshare)** *(opcional)*: permite editar el mismo archivo entre varias personas en tiempo real. Es útil para los talleres del curso, que se desarrollan en parejas o en grupos de tres.

> ⚠️ **Sugerencia:** configure el editor para que guarde y formatee el código por usted. Abra la paleta de comandos (`Ctrl + Shift + P` o `Cmd + Shift + P`), busque **Preferences: Open User Settings (JSON)** y agregue estas dos líneas:
>
> ```json
> "editor.formatOnSave": true,
> "files.autoSave": "onFocusChange"
> ```
>
> La primera hace que, al guardar, ElixirLS corrija la sangría, los espacios y los saltos de línea según el estilo oficial de Elixir. La segunda guarda el archivo cada vez que usted pasa del editor a otra parte, por ejemplo a la terminal para ejecutar el programa. Así se evita un error muy común, que es ejecutar el programa sin haber guardado y ver el resultado de la versión anterior.

### 6. Crear y ejecutar un programa en Elixir desde Visual Studio Code

Cree un archivo llamado `saludo.exs` y ábralo en Visual Studio Code. Después, escriba el siguiente código en el archivo:

```elixir
IO.puts("¡Hola, mundo!")
```
Ejecute el programa usando el siguiente comando en la terminal (asegúrese de ejecutarlo en la carpeta donde se encuentra el archivo):

```bash
elixir saludo.exs
```

Al ejecutar el programa, debería ver lo siguiente en la consola:

```bash
¡Hola, mundo!
```

> ⚠️ **Sugerencia:** no es necesario salir de Visual Studio Code para ejecutar el programa. Abra la **terminal integrada** desde el menú **Terminal → Nueva terminal**, que se ubica automáticamente en la carpeta del proyecto, y ejecute allí el mismo comando. Recuerde la advertencia sobre PowerShell si trabaja en Windows.

## Archivos `.exs` y `.ex`

Elixir utiliza dos extensiones de archivo con propósitos distintos:

- **`.exs`** (*Elixir script*): se interpreta y compila **en memoria** cada vez que se ejecuta, sin generar archivos adicionales. Es ideal para practicar, hacer pruebas rápidas y resolver ejercicios. Es la extensión que usaremos en las próximas guías.
- **`.ex`**: se compila a *bytecode* en archivos `.beam` que la máquina virtual carga y ejecuta. Es la extensión que se usa en los proyectos reales.

## Ejercicios propuestos

### Ejercicio 1

Explore el intérprete interactivo (IEx) ejecutando cada una de las siguientes líneas y observando el resultado que produce:

```elixir
h IO.puts      # Muestra la documentación de una función específica
i "hola"       # Muestra información sobre un valor: tipo, módulo y detalles
IO.puts(2 + 3 * 4)
```

¿Qué información le entrega `i` sobre el texto `"hola"` que no era evidente a simple vista?

### Ejercicio 2

Consulte con `h` la documentación de `IO.inspect` y de `String.upcase`. Luego ejecute en IEx:

```elixir
IO.puts([1, 2, 3])
IO.inspect([1, 2, 3])
```

¿Qué diferencia observa entre la salida de `IO.puts` y la de `IO.inspect`?

### Ejercicio 3

Cree un archivo `datos.exs` en Visual Studio Code que imprima su nombre, su programa académico y el año actual, cada uno en una línea distinta. Ejecútelo con `elixir datos.exs` desde la terminal integrada de Visual Studio Code.

Luego escriba deliberadamente un error (por ejemplo, `IO.puts(` sin cerrar el paréntesis) y observe cómo lo reportan **ElixirLS** y **Error Lens** antes siquiera de ejecutar el programa.
