# Elixir

En esta guía se abordarán los siguientes temas:

- Origen del lenguaje Elixir y su relación con Erlang, la BEAM y OTP.
- Características clave y usos comunes de Elixir.
- Instalación de Erlang y Elixir.
- El intérprete interactivo (IEx) y el primer programa.
- Configuración del entorno de trabajo con Visual Studio Code.

Elixir es un lenguaje de programación funcional, concurrente y de tipado dinámico diseñado para construir aplicaciones escalables y mantenibles. Fue creado en 2011 por el programador brasileño **José Valim**, un reconocido desarrollador de la comunidad de Ruby on Rails.

## La base de Elixir: Erlang, la BEAM y OTP

José Valim buscaba un lenguaje que combinara la productividad y la sintaxis elegante de Ruby con una solución nativa para la concurrencia y la tolerancia a fallos. En lugar de construirlo todo desde cero, decidió apoyarse en la **plataforma de Erlang**, creada en los años 80 para sistemas de telecomunicaciones que debían permanecer activos 24/7 sin interrupciones. La filosofía de Elixir puede resumirse así: *"la productividad y elegancia de Ruby sobre la potencia y robustez de Erlang"*.

Esto significa que el código Elixir no se ejecuta directamente sobre el sistema operativo: se compila a *bytecode* que corre sobre la **BEAM** (*Bogdan/Björn's Erlang Abstract Machine*), la máquina virtual de Erlang. La BEAM es para Elixir lo que la JVM es para Java, solo que fue diseñada desde el inicio para ejecutar miles de procesos concurrentes y para recuperarse de fallos.

Sobre la BEAM se apoya **OTP** (*Open Telecom Platform*), el conjunto de principios y herramientas que Erlang y Elixir usan para organizar la concurrencia. Su idea central es **"dejarlo fallar" (*let it crash*)**: en lugar de anticipar cada error posible con código defensivo, el sistema se divide en procesos pequeños vigilados por **supervisores**, que reinician automáticamente a un estado seguro cualquier proceso que falle. Así se construyen sistemas que se "auto-reparan".

## Características clave de Elixir

-   **Funcional**: promueve funciones puras, inmutabilidad y un estilo declarativo. Es el eje de este curso.
-   **Concurrente**: crear un proceso para ejecutar una tarea en paralelo es trivial y de bajo costo; no es una característica añadida al lenguaje.
-   **Tolerante a fallos**: los árboles de supervisión contienen los errores sin detener la aplicación.
-   **Escalable**: la BEAM aprovecha todos los núcleos de una máquina, y Elixir distribuye procesos entre varias máquinas de la red como si fueran una sola.
-   **Interoperabilidad con Erlang**: cualquier librería de Erlang puede usarse desde Elixir sin penalización de rendimiento.

## Usos comunes

Aunque Elixir puede usarse para muchos tipos de aplicaciones, es especialmente popular en:

- Desarrollo de aplicaciones web (con el framework Phoenix).
- Sistemas de mensajería y comunicación en tiempo real.
- Servicios backend de alta concurrencia y baja latencia.

## Elixir y Erlang a nivel empresarial

Según la [página oficial de Elixir](https://elixir-lang.org/cases.html) y [un artículo de Netguru](https://www.netguru.com/blog/10-companies-use-elixir) estos son algunos ejemplos de su uso a nivel empresarial. Note que algunos corresponden a **Erlang** y no a Elixir: al compartir la misma máquina virtual, ambos ofrecen las mismas garantías de concurrencia y tolerancia a fallos.

- **WhatsApp** *(Erlang)*: aplicación de mensajería instantánea. Un caso clásico de la BEAM, muy anterior a la existencia de Elixir.
- **Heroku** *(Erlang)*: el enrutador de su plataforma como servicio (PaaS) en la nube.
- **Financial Times** *(Elixir)*: periódico internacional.
- **Bleacher Report** *(Elixir)*: plataforma de noticias deportivas.
- **PepsiCo** *(Elixir)*: empresa multinacional de alimentos y bebidas.
- **Pinterest** *(Elixir)*: red social visual basada en imágenes y videos.

## Ambiente de trabajo con Elixir

Elixir puede ser instalado en diferentes arquitecturas y sistemas operativos: GNU/Linux (diferentes distribuciones), MacOS y Windows.

### 1. Instalación Elixir y Erlang

Ingrese a [https://elixir-lang.org/install.html](https://elixir-lang.org/install.html) e instale Erlang y Elixir en su sistema. Tenga en cuenta que Elixir depende de Erlang, por lo que primero debe instalar Erlang y luego Elixir.

Para GNU/Linux y MacOS, Elixir se instala junto con Erlang automáticamente, pero en Windows debe instalar Erlang por aparte, puede descargar el instalador desde: [https://www.erlang.org/downloads.html](https://www.erlang.org/downloads.html).

> **⚠️ Importante (GNU/Linux):** Los paquetes disponibles en los repositorios de las distribuciones (`apt`, `yum`, etc.) suelen estar **varias versiones atrasados** respecto a la versión oficial. Si su gestor de paquetes instala una versión antigua, prefiera el instalador oficial o un gestor de versiones como [mise](https://mise.jdx.dev/) o [asdf](https://asdf-vm.com/), que permiten instalar y cambiar entre versiones específicas de Erlang y Elixir.

Para verificar que todo se haya instalado correctamente, abra una terminal (CMD en Windows) y ejecute el siguiente comando:

```bash
elixir -v
```

La salida muestra **dos** datos importantes, uno por cada herramienta instalada:

```bash
Erlang/OTP 29 [erts-17.0.5] [source] [64-bit] [smp:10:10] [ds:10:10:10] [async-threads:1] [jit] [dtrace]

Elixir 1.20.2 (compiled with Erlang/OTP 29)
```

La primera línea confirma que **Erlang/OTP** está instalado, y la segunda que **Elixir** lo está y sobre qué versión de Erlang fue compilado. Los números pueden variar según su instalación y sistema operativo; las versiones al momento de escribir este documento son **Elixir 1.20.2** sobre **Erlang/OTP 29**.

> **⚠️ Versión mínima para el curso:** se requiere **Elixir 1.15 o superior**, con **Erlang/OTP 26 o superior**. Si su salida muestra números menores, actualice antes de continuar con las siguientes guías.

> **⚠️ Importante:** En Windows, puede ser necesario reiniciar el computador después de la instalación para que las variables de entorno se actualicen correctamente. Si después de reiniciar, el comando `elixir -v` no funciona o `iex` no se reconoce, asegúrese de que las rutas de Erlang y Elixir estén correctamente configuradas en las variables de entorno del sistema.

### 2. Primer programa en Elixir

El primer programa que se suele escribir en cualquier lenguaje de programación es "¡Hola, mundo!". En Elixir, puede hacerlo de dos maneras: usando el intérprete interactivo (IEx), que veremos a continuación, o creando un archivo `.exs` y ejecutándolo, lo cual haremos más adelante en la sección de Visual Studio Code.

El **intérprete interactivo (IEx)** es una herramienta que permite escribir y ejecutar código Elixir línea por línea, lo que facilita la experimentación y el aprendizaje del lenguaje. No está diseñado para ejecutar programas completos, sino para probar fragmentos de código y explorar las características del lenguaje de manera interactiva.

En la terminal, escriba el siguiente comando para iniciar el intérprete interactivo de Elixir (IEx):

```bash
iex
```

> **⚠️ Importante (Windows):** En **PowerShell**, `iex` está reservado como alias del comando `Invoke-Expression`, por lo que **no iniciará** el intérprete de Elixir y producirá un error confuso. En PowerShell debe escribir `iex.bat`, o bien abrir una terminal **CMD**. Tenga esto presente también en la terminal integrada de Visual Studio Code, que en Windows usa PowerShell de manera predeterminada.

Y escriba lo siguiente:

```elixir
IO.puts("¡Hola, mundo!")
```

Al dar **Enter**, debería ver lo siguiente en la consola.

```bash
¡Hola, mundo!
:ok
```

`IO` es un módulo que proporciona funciones para realizar operaciones de entrada y salida. La función `puts` se utiliza para imprimir texto en la consola. El resultado `:ok` indica que la operación se realizó correctamente.

>**⚠️ Importante:** Para salir de `iex`, puede presionar `Ctrl + C` dos veces. También puede resultar útil acceder al menú de ayuda escribiendo `h()` y luego presionando **Enter**, en este menú de ayuda encontrará información sobre las funciones disponibles y cómo utilizarlas.

El ayudante `h` no solo sirve para el menú general: si se escribe seguido del nombre de una función, muestra **la documentación oficial de esa función** sin salir de la terminal. Por ejemplo, `h IO.puts` explica qué hace, qué parámetros recibe y qué retorna. Es la forma más rápida de consultar el lenguaje mientras se programa.

### 3. Control de versiones con Git

Instale Git desde [https://git-scm.com/downloads](https://git-scm.com/downloads). No es una herramienta de Elixir, pero es indispensable en cualquier proyecto de software profesional: permite llevar un historial de los cambios del código y trabajar en equipo sobre el mismo proyecto.

En este curso, **el proyecto final debe entregarse como un repositorio Git**, por lo que conviene instalarlo desde ahora para evitar contratiempos. Después de instalarlo, configure su identidad ejecutando en la terminal:

```bash
git config --global user.name "Su Nombre"
git config --global user.email "sucorreo@uniquindio.edu.co"
```

### 4. Instalación de Visual Studio Code

Para programar en Elixir es recomendable usar un editor de código fuente que facilite la escritura y ejecución del código. Uno de los más populares y ampliamente utilizados es **Visual Studio Code (VS Code)**.

Ingrese a [https://code.visualstudio.com/Download](https://code.visualstudio.com/Download) e instale Visual Studio Code. Es un editor ampliamente utilizado en la industria del software, con soporte para múltiples lenguajes de programación, incluyendo Elixir.

Una de sus características más destacadas es su extensibilidad a través de una amplia variedad de extensiones que mejoran la funcionalidad del editor.

### 5. Instalar extensiones en Visual Studio Code

Ingrese a Visual Studio Code (VS Code) e instale las siguientes extensiones:

- **[ElixirLS: Elixir support and debugger for VS Code](https://marketplace.visualstudio.com/items?itemName=JakeBecker.elixir-ls)** *(indispensable)*: aporta resaltado de sintaxis, autocompletado, detección de errores mientras se escribe, documentación al pasar el cursor sobre una función y formateo automático del código.
- **[Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)** *(recomendada)*: muestra los errores y advertencias **junto a la línea** que los produce, en lugar de dejarlos ocultos en el panel inferior. Ayuda mucho a detectar equivocaciones de sintaxis apenas ocurren.
- **[Live Share](https://marketplace.visualstudio.com/items?itemName=MS-vsliveshare.vsliveshare)** *(opcional)*: permite editar el mismo archivo entre varias personas en tiempo real. Es útil para los talleres del curso, que se desarrollan en parejas o en grupos de tres.

> ⚠️ **Sugerencia:** active el formateo automático para que ElixirLS ordene su código cada vez que guarde el archivo. Abra la paleta de comandos (`Ctrl + Shift + P` o `Cmd + Shift + P`), busque **Preferences: Open User Settings (JSON)** y agregue:
>
> ```json
> "editor.formatOnSave": true
> ```
>
> Esto aplica automáticamente las convenciones oficiales de estilo de Elixir, un tema que se abordará en la siguiente guía.

### 6. Crear y ejecutar un programa en Elixir desde Visual Studio Code

Cree un archivo llamado `saludo.exs` y ábralo en Visual Studio Code. Después, escriba el siguiente código en el archivo:

```elixir
IO.puts("¡Hola, mundo!")
```
Ejecute el programa usando el siguiente comando en la terminal (asegúrese de ejecutarlo en la carpeta donde se encuentra el archivo):

```bash
elixir saludo.exs
```

Al ejecutar el programa, debería ver lo siguiente en la consola:

```bash
¡Hola, mundo!
```

> ⚠️ **Sugerencia:** no es necesario salir de Visual Studio Code para ejecutar el programa. Abra la **terminal integrada** desde el menú **Terminal → Nueva terminal**, que se ubica automáticamente en la carpeta del proyecto, y ejecute allí el mismo comando. Recuerde la advertencia sobre PowerShell si trabaja en Windows.

## Archivos `.exs` y `.ex`

Elixir utiliza dos extensiones de archivo con propósitos distintos:

- **`.exs`** (*Elixir script*): se interpreta y compila **en memoria** cada vez que se ejecuta, sin generar archivos adicionales. Es ideal para practicar, hacer pruebas rápidas y resolver ejercicios. Es la extensión que usaremos en las próximas guías.
- **`.ex`**: se compila a *bytecode* en archivos `.beam` que la máquina virtual carga y ejecuta. Es la extensión que se usa en proyectos reales, como veremos al final del curso con la herramienta **Mix**.

## Ejercicios propuestos

### Ejercicio 1

Explore el intérprete interactivo (IEx) ejecutando cada una de las siguientes líneas y observando el resultado que produce:

```elixir
h IO.puts      # Muestra la documentación de una función específica
i "hola"       # Muestra información sobre un valor: tipo, módulo y detalles
IO.puts(2 + 3 * 4)
```

¿Qué información le entrega `i` sobre el texto `"hola"` que no era evidente a simple vista?

### Ejercicio 2

Consulte con `h` la documentación de `IO.inspect` y de `String.upcase`. Luego ejecute en IEx:

```elixir
IO.puts([1, 2, 3])
IO.inspect([1, 2, 3])
```

¿Qué diferencia observa entre la salida de `IO.puts` y la de `IO.inspect`? Esta distinción se explicará formalmente en la próxima guía.

### Ejercicio 3

Cree un archivo `datos.exs` en Visual Studio Code que imprima su nombre, su programa académico y el año actual, cada uno en una línea distinta. Ejecútelo con `elixir datos.exs` desde la terminal integrada de Visual Studio Code.

Luego escriba deliberadamente un error (por ejemplo, `IO.puts(` sin cerrar el paréntesis) y observe cómo lo reportan **ElixirLS** y **Error Lens** antes siquiera de ejecutar el programa.
