# Guías de apoyo para Programación III - Elixir

[![Licencia: CC BY-SA 4.0](https://img.shields.io/badge/Licencia-CC%20BY--SA%204.0-green.svg)](https://creativecommons.org/licenses/by-sa/4.0/deed.es)

[![GitHub Pages](https://img.shields.io/badge/Sitio-GitHub%20Pages-blue.svg)](https://caflorezvi.github.io/guias-programacion3/)

Este repositorio está dedicado a recopilar y organizar los recursos relacionados con el curso de **Programación III**, con un enfoque específico en la programación funcional utilizando **Elixir**. Aquí encontrarás documentos, guías de apoyo, ejemplos de código y otros materiales que te ayudarán a comprender mejor los conceptos y técnicas asociados con este lenguaje de programación.

Iniciando con una introducción a Elixir, exploraremos sus características principales, su sintaxis y cómo se diferencia de otros lenguajes de programación. A medida que avancemos, abordaremos temas como la concurrencia, el manejo de procesos, la programación funcional y el uso de herramientas específicas de Elixir.

📖 **Versión web:** [caflorezvi.github.io/guias-programacion3](https://caflorezvi.github.io/guias-programacion3/)
